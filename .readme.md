# 🔥 Firebase Web Push Token Generator (Pure HTML + JS)

A **minimal** Firebase Cloud Messaging (FCM) web client for generating **device tokens** — perfect for testing push notifications (like with a NestJS backend).

---

## 🚀 Features

* Generate **FCM web tokens** in your browser
* Works with a simple HTML page
* Handles **service worker registration**
* Supports **foreground & background** notifications

---

## 🧩 Folder Structure

```
/firebase-web-push-test
│
├── index.html                 # Main page
├── firebase.js                # Main JS logic (registers SW, gets token)
├── firebase-config.js         # Firebase config + VAPID key
└── firebase-messaging-sw.js   # Background notification handler
```

---

## ⚙️ Setup Steps

### 1️⃣ Add your Firebase credentials

In **`firebase-config.js`**, put your Firebase info and **VAPID key**:

```js
// firebase-config.js
const firebaseConfig = {
  apiKey: "YOUR_FIREBASE_API_KEY",
  authDomain: "YOUR_FIREBASE_AUTH_DOMAIN",
  projectId: "YOUR_FIREBASE_PROJECT_ID",
  storageBucket: "YOUR_FIREBASE_STORAGE_BUCKET",
  messagingSenderId: "YOUR_FIREBASE_MESSAGING_SENDER_ID",
  appId: "YOUR_FIREBASE_APP_ID",
  measurementId: "YOUR_FIREBASE_MEASUREMENT_ID",
  vapidKey: "YOUR_PUBLIC_VAPID_KEY"
};
```

---

### 2️⃣ Run a local server

Service workers **don’t run** on `file://` URLs — you must serve over `http://`.

If you have **Node.js**, run:

```bash
npx serve .
```

Then open your browser at:

👉 [http://localhost:8080](http://localhost:8080)

---

### 3️⃣ Generate an FCM Token

1. Open the page
2. Click **“Generate FCM Token”**
3. Allow notification permission
4. Copy your generated token (shown in the textbox)

You can now send a test push from:

* **Firebase Console → Cloud Messaging → Send test message**

## 🧹 Troubleshooting

| Issue                                                   | Fix                                                                                                              |
| ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `InvalidAccessError: applicationServerKey is not valid` | Your VAPID key is wrong or missing. Copy it from **Firebase Console → Cloud Messaging → Web Push certificates**. |
| Service Worker registration failed                      | Make sure you’re not opening the file directly (use `npx serve .`).                                              |
| Token not showing                                       | Check the browser **console logs** (press F12 → Console).                                                        |
